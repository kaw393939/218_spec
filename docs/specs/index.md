## Add a specification

1. Copy the [specification template](./template) to `docs/specs/your-program.md`.
2. Replace the prompts with the program's actual requirements.
3. Add the program to the table above with its status, owner, and pull request link.
4. Open a pull request and follow the [review process](../review/).

Use **Draft**, **In review**, **Approved**, or **Superseded** consistently. Mark a specification approved only after a reviewer explicitly approves it.

Individual specifications are searchable automatically. Add frequently used pages to the sidebar in `docs/.vitepress/config.mts`.
