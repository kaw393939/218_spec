# Start here

**Make Rock, Paper, Scissors work with AI—and show why you trust the result.** The browser shell is supplied; you and AI finish the rules for one round.

[Follow the starter README →](https://github.com/kaw393939/is218-rps-starter#readme)

This is a self-paced, guided lab. The README gives the actions and checkpoints. Create your own GitHub copy, clone it with SSH, and use one local Codex chat inside ChatGPT desktop to discuss, save the spec, build, test, and review. Use terminal Git and a browser; VS Code is optional.

The [process guide](./practice) explains the five steps. The [checks guide](./checks) includes a worked failure example, and [setup help](./setup) is there if something fails. These are references, not extra assignments. Return to your last completed README checkpoint when ready.
